Workbook format

The first worksheet must be named Flashcard_Import. Use one row per card and these exact columns:

card_id, deck, topic, front, clue, answer, learning_point, source, tags, difficulty, status

Difficulty must be Foundation, Intermediate or Advanced. Status can be Draft, Reviewed or Published. Only Published cards appear in the learner flashcard area. Each card ID should be unique and lowercase, with hyphens between words.

Every card in this upload will be assigned to the package or packages selected above. Existing card IDs are updated when you upload the workbook again.
