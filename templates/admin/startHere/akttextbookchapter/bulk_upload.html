Workbook format

The first sheet must be named AKT_Import. Use one row per chapter and these exact columns:

chapter_id, curriculum_area, topic, curriculum_outcomes, title, order, body_html, sources

Use a permanent lowercase ID such as cardio-hypertension-diagnosis. Put the RCGP learning outcome wording or references in curriculum_outcomes, with one item per line. Put the formatted chapter HTML in body_html; separate multiple references in sources with line breaks. Choose the relevant package(s) once above.

Imported chapters are saved as drafts. Select reviewed chapters in the chapter list and use the publish action when ready.
